# xxyara

A C11 implementation of [YARA-X](https://github.com/VirusTotal/yara-x) with the
`yr` CLI and its C API. It requires [xxfclib](https://github.com/horsicq/xxfclib).
Some compiled-rule cases differ from YARA-X 1.23.0.

See the [build instructions](docs/BUILD.md), [examples](examples/README.md),
[compatibility notes](docs/COMPATIBILITY.md), and [benchmarks](docs/BENCHMARKS.md).
